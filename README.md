# online-store using HTML - CSS & JS
A responsive e-commerce website built with HTML, CSS, and JavaScript, featuring product listings, a shopping cart, and a checkout form integrated with Google Sheets using Google Apps Script.
About This Project

This is a learning project built by following a YouTube tutorial to practice HTML, CSS, and JavaScript. I implemented the core e-commerce features and explored integrating Google Sheets using Google Apps Script.

What I Learned
Building a responsive user interface
Managing a shopping cart with JavaScript
Handling form submissions
Integrating Google Sheets with Google Apps Script
